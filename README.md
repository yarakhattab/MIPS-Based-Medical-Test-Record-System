# 🧬 MIPS-Based Medical Test Record System

## 📖 Project Description  
This repository showcases my implementation of Project #1 for the Computer Architecture course at Birzeit University. The goal was to build a Medical Test Record System using MIPS assembly language that can store, process, and retrieve patient medical data in a structured and efficient way.

## 🔧 Core Capabilities  
- 🗃️ Add and manage patient test records  
- 🔍 Lookup tests using Patient ID  
- 📅 Filter tests by specific date range  
- ⚠️ Detect abnormal values in test results  
- 📊 Compute average readings per test type  
- ✏️ Edit or remove existing test entries  
- 🛡️ Input validation and error notifications  

## 📁 Project Structure  
- `MedicalTest.txt`: The full MIPS assembly source code  
- `code.asm`: Sample inputs and their expected results  
- `README.md` and additional docs: System functionality, rules for validation, and error-handling details  

## 🚀 Getting Started  
To run the system:  
1. Clone the repository
2. Open `MedicalTest.asm` using the [MARS MIPS simulator](http://courses.missouristate.edu/kenvollmar/mars/)  
3. Run the program and navigate using the text-based interface  
4. Input test data and explore the available operations (search, update, compute, etc.)  
5. Use provided test cases to verify correct functionality  

## 📋 Prerequisites  
- MIPS simulator (Recommended: MARS)  
- Plain text dataset of medical test records
